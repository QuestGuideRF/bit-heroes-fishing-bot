## 🎯 Введение

Эта программа позволяет **автоматически рыбачить** с использованием заданного количества приманки. Просто выберите количество приманки, которое вы хотите использовать, нажмите кнопку "Старт" и позвольте боту рыбачить за вас!

✨ **Что делает этого бота особенным:**
- 🎯 Автоматизированная рыбалка без вашего участия
- 🚀 Работает лучше, чем человек
- ⚡ Высокий процент успешных поклёвок
- 💪 Минимальные усилия, максимальный результат

> **Примечание:** Программа не гарантирует 100% успеха, но гарантирует очень высокий процент успешных поклёвок при минимальных усилиях.

**Pull request'ы приветствуются и поощряются!** 🌟

## 🚀 Как использовать

### 💻 Windows

Версия для Windows включает в себя **графический интерфейс** и расширенные настройки. Совместима как с **Steam**, так и с **Kongregate**.

📖 Для более подробной информации см. [README в разделе csharp](./csharp).

### 🍎 Mac/Linux

Эта версия работает на **Java**. Убедитесь, что у вас установлена Java на вашем компьютере. Это инструмент только для командной строки.

📥 **Быстрый старт:**
1. Скачайте [bh-fisher.jar](https://github.com/tiemonl/Bit-Heroes-Fishing-Bot/releases) из раздела релизов
2. Запустите через командную строку

Подпись относится к текущей версии проекта.
